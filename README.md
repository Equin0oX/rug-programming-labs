# RUG Programming Labs

Coursework for Programming courses at the University of Groningen (RUG).

## Contents

| Folder | Description |
| --- | --- |
| `labAssignments/` | Graded lab assignments (area, hit detection, money formatter, rock paper scissors, simple encoding, hello world) |

All code is Python 3.

## Running

```sh
python labAssignments/area.py
```

Programs read their input from stdin.
