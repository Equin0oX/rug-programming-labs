# RUG Programming Labs

Coursework for Programming courses at the University of Groningen (RUG).

## Contents

| Folder | Description |
| --- | --- |
| `labAssignments/` | Graded lab assignments (area, hit detection, money formatter, rock paper scissors, simple encoding, hello world) |
| `Imperative_Programming_wk1_code/` | Imperative Programming — week 1 exercises (functions, numbers, hello world) |
| `Imperative_Programming_wk2_code/` | Imperative Programming — week 2 exercises (range checks, month days) |
| `Imperative_Programming_wk4_code/` | Imperative Programming — week 4 exercises (lists, swapping, letter counting) |

All code is Python 3.

## Running

```sh
python labAssignments/area.py
```

Programs read their input from stdin.
